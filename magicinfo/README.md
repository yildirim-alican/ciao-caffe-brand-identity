# Samsung MagicINFO packages

Upload as **Content › Create › Upload Web Content**, start page **`index.html`**. Each ZIP contains a single self-contained `index.html` (offline — fonts and logo embedded).

| Package | Board | Display |
|---|---|---|
| **`Ciao_Ekran1_Sicak.zip`** | intro (red) → hot drinks, 60 s loop | **Screen 1** — left |
| **`Ciao_Ekran2_Soguk.zip`** | intro (blue) → cold drinks → desserts, 60 s loop, 30 s offset | **Screen 2** — right |
| `Ciao_Sicak_Liste.zip` | hot list board | optional |
| `Ciao_Soguk_Liste.zip` | cold list board | optional |
| `Ciao_Tatli.zip` | desserts & snacks | optional |
| `Ciao_Sicak_Gorselli.zip` | hot board with image panel (7 drinks) | optional |
| `Ciao_Soguk_Gorselli.zip` | cold board with image panel (5 drinks) | optional |
| `Ciao_Intro_Sicak.zip` · `Ciao_Intro_Soguk.zip` | brand intro only | events |

Schedule 24 hours, every day, never expired, one schedule per device group. Keep both displays on the same time zone with automatic time.
