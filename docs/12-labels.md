# 12 · Price labels

Every product sold from the display case, the counter or the bar front carries a small price label in the same style as the menu boards.

<p align="center"><img src="../labels/Ciao_Etiketler_Onizleme.png" alt="Price labels" width="100%"></p>

## Format

| | |
|---|---|
| Size | **80 × 50 mm** (8 × 5 cm), landscape |
| Background | near-black `#0B0A09`, full bleed |
| Logo | Ciao logo, white, top-left, 10 mm high, 4 mm from the edges |
| Name | *Kaushan Script*, ~10 mm, in the product's own colour, centred |
| Product name | *Barlow Condensed* Medium italic, ~4 mm, white, under the name |
| Price | *Barlow Condensed* Bold italic, ~5.6 mm, white, with `₺` |
| Drinks | name in *Barlow Condensed* SemiBold italic, white — bottled drinks are read, not tasted |

Long names shrink automatically so nothing touches the edge. Each dessert has its own colour, taken from the product (strawberry pink for *Blush*, lotus gold for *Golden*, carrot orange for *Bunny House* …).
