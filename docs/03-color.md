# 03 · Colour

Each board has its own theme so guests can tell hot, cold and dessert apart from across the room. All three share the same neutrals, so they still read as one brand.

## Themes

| Token | Hot (Sıcaklar) | Cold (Soğuklar) | Dessert (Tatlı) |
|---|---|---|---|
| `band` — header band + image panel | `#F54021` Ciao Red | `#1670B5` Ice Blue | `#7A3E26` Cocoa |
| `brand` — section titles, stars, accents | `#F54021` | `#3DA3EC` Sky | `#F5A35C` Caramel |
| `bg` — list surface | `#15110F` | `#101315` | `#15110F` |
| `line` — rules under headers | `#3A2D25` | `#2C3238` | `#3A2D25` |
| `mute` — descriptions, column labels | `#ADA196` | `#A7ADB2` | `#ADA196` |
| `card` / `card-line` | `#211A16` / `#4A3329` | `#1A1E22` / `#333B42` | `#211A16` / `#4A3329` |

## Neutrals

| Token | Hex | Use |
|---|---|---|
| `cream` | `#FFF8F1` | all primary text, outlines of illustrations |
| `ink` | `#1A1210` | pills, badges, price chips, sticker slogans |
| `gold` | `#E8C07A` | dessert accents, "YAKINDA" tag, ticket star |

## Contrast

Body text is cream on near-black (≈ 16:1). Descriptions use the `mute` tone (≈ 7:1). Prices are always cream and bold. On coloured bands, text is cream at display sizes only (≥ 18 px bold or ≥ 24 px).

Machine-readable values: [`brand/tokens/tokens.json`](../brand/tokens/tokens.json) · [`tokens.css`](../brand/tokens/tokens.css).
