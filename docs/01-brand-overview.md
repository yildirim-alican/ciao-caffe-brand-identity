# 01 · Brand overview

## The brief

Ciao Caffè is a franchise coffee brand. Each store needed an in-store menu that could:

- show a large range (≈100 items: hot, cold, desserts, snacks, extras) on **two 1920×1080 screens** without feeling crowded;
- push the drinks the brand wants to sell (signatures, barista picks, new items);
- be easy for any franchisee to run — no CMS, no server, no internet dependency;
- stay consistent with the price list the staff use at the till.

## Personality

| Trait | How it shows |
|---|---|
| **Warm, Italian-flavoured** | the name *Ciao*, Italian size names (UNICO · PICCOLO · GRANDE), script headlines |
| **Playful, street-casual** | hand-lettered logo, marker-pen sticker slogans ("Sıcacık bir ciao!"), a star as the recurring mark |
| **Confident and clear** | condensed sans for every list and price, strict columns, generous rhythm |
| **Lively, never noisy** | motion that tells the product story (pour → fill → serve) and then rests |

## Voice

Short, friendly, Turkish first. Slogans greet the guest with the brand name: *Sıcacık bir ciao!* (hot), *Buz gibi bir ciao!* (cold), *Tatlı bir ciao!* (desserts). The intro tag line is **More Coffee More Life**.

## The system at a glance

```
            ┌──────────────── Ciao star ────────────────┐
            │  the logo's star becomes the brand mark:  │
            │  Ciao Selection badges, list stars,       │
            │  the backdrop star, intro sparkles        │
            └───────────────────────────────────────────┘
 Logo ─ Colour themes (hot · cold · dessert) ─ Typography (3 faces)
   │              │                                  │
   └── Components (bands, rows, cards, slides, pills, tickets)
                  │
          Motion (pour / fill / float / twinkle) + Illustration (vector drinkware)
                  │
          Screens (2 synced loops) ─ Price list ─ POS list
```

## Sub-brands inside the menu

- **Ciao Signature** — drinks that exist only at Ciao (Tarantino, Pistachio White Hot, Ruby, Cincirella, Salted Karamel Chocolate, Kori Kohi, Berry Hibiscus Cooler, Cool Lime Refresha).
- **Ciao Selection** — the barista's picks, marked everywhere with the star.
- **Ciao Duetto** — dessert × coffee pairings on the dessert board (*duetto*: Italian for duet — dessert and coffee share the stage).
